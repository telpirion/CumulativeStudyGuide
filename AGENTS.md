# Repo and Project Instructions

## General

+ Use files that contain "R supplement to Business Statistics" in the title to
  enhance the .Rmd study guide files.
+ Always knit all of the .Rmd files after performing updates to an .Rmd file.
+ Always update README.md to include newly added files.

## Jupyter notebooks

+ All Jupyter notebooks in this repo use R code.
+ Always include the files that contain "PracticeProblems" in the title in the
  Jupyter notebook.
+ Always include the content from Exercises.txt in the Jupyter notebook.

## R Code

+ Always plot boxplots horizontally.
+ Never call `par(mfrow = c(1, 1))` after a plot.
+ Never use `cat()` to print a string. Use `print(sprintf())` instead.
+ Never include comments in the R code unless requested.
+ Always reference files in the /data folder by their live URL: https://raw.githubusercontent.com/telpirion/CumulativeStudyGuide/refs/heads/main/data/[DATA_FILE].csv
