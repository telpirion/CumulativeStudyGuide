Cumulative Study Guide: Business Statistics with R

A comprehensive, cumulative study guide and computational reference for applied business statistics. This repository combines textbook theory, mathematical formulas, and practical R implementations.

Overview

This repository provides reproducible study materials designed to reinforce core statistical foundations and their application in R. Each module includes: - Conceptual Summaries: Clear definitions, core business use cases, and statistical terminology. - Mathematical Formulations: LaTeX-rendered formulas for descriptive and inferential statistics. - R Code Implementations: Reproducible scripts for data classification, descriptive tables, frequency distributions, and visual diagnostics. - Interactive Practice: Applied exercises and self-assessment questions available in Jupyter Notebook format.

Prerequisites & Setup

R Environment

  • R version: \(\ge\) 4.0.0
  • Recommended IDE: Positron or RStudio

Required R Packages

Install the necessary visualization and publishing packages from CRAN:

install.packages(c("rmarkdown", "knitr", "ggplot2", "gridExtra"))

Rendering the Study Guides

Each study guide is authored in R Markdown (.Rmd) and configured to compile into a standalone HTML report with a floating table of contents in the guides/ directory.

To render via the R console:

# Render Week 1
rmarkdown::render("Week1.Rmd", output_dir = "guides")

# Render Week 7 (uses custom knit hook targeting guides/)
rmarkdown::render("Week7.Rmd", output_dir = "guides")

Or from the command line:

Rscript -e 'rmarkdown::render("Week1.Rmd", output_dir = "guides")'
Rscript -e 'rmarkdown::render("Week7.Rmd", output_dir = "guides")'

Using Positron or Quarto CLI:

quarto render Week7.Rmd
